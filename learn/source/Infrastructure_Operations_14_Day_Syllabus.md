# Administration & Technical Configuration for Infrastructure Operations Freshers (Linux, Windows Server, AWS, Nutanix, Networking, Security, ITSM & Automation)

**Duration:** 14 intensive training days (approximately 98–112 hours, at 7–8 hours per day)  
**Training approach:** Accelerated foundation and operational readiness, with hands-on labs, verification evidence, controlled troubleshooting, and integrated operations practice.  
**Scope:** Coverage of the original Day 1–11 Linux/AWS syllabus plus Windows Server, RHEL, S3 backup/DR, HPE/iLO, Nutanix AOS/AHV/Prism, HYCU, enterprise networking, FortiGate, BIG-IP, centralized logging, ServiceNow, PalletControl, privileged access, IAM audit, and operations automation.

## 1. Orientation & Linux Administration Foundations

### 1.1. Day 1

- Concept/Lecture: Infrastructure administration roles and responsibilities, L1/L2 support boundaries, operational safety, production and non-production environment separation, change authorization, least-privilege principles, standard operating procedures, runbooks, incident escalation, access management, configuration baselines, asset inventory, audit evidence, and lab readiness; Linux architecture, kernel, shell, distributions, Red Hat Enterprise Linux (RHEL) and other Linux distributions, filesystem hierarchy, CLI navigation, absolute and relative paths, file and directory operations, command syntax, pipes, redirection, command history, help utilities, safe command execution, users and groups, ownership, file permissions, chmod/chown/chgrp, umask, sudo, SSH authentication, SSH key management, and secure administrative access.
- Assignment/Lab: Prepare the administrative workstation, approved access checklist, Linux/RHEL lab environment, evidence repository, and personal learning baseline; perform CLI navigation, file creation, copying, moving, deletion, searching, and text-processing exercises; create and manage controlled users and groups, configure ownership and permissions, establish least-privilege sudo access, generate and configure SSH keys, verify authorized and denied access, document executed commands, and submit system inventory, access verification, and configuration evidence.

### Delivery & Scope Notes

- The 14-day curriculum is an **accelerated coverage and operational-readiness program**, not a claim of advanced product mastery. Hands-on delivery assumes preconfigured labs, prepared sample datasets, authorized accounts, and mentor supervision.
- **Windows Server (All editions):** Training addresses server generations and edition differences, while hands-on installation may focus on selected licensed editions. Edition-specific features must be verified against the chosen Windows Server release.
- **PalletControl:** Exercises use the organization's actual product documentation and procedures where its implementation differs from a general IT asset inventory workflow.
- **PS/Gateway and AccessCheck:** Product-specific workflows must follow the organization's approved runbooks, access permissions, and real configurations; undocumented product capabilities are not assumed.
- **Outlook/MAPI:** COM/MAPI automation exercises require a compatible classic Outlook deployment. New Outlook compatibility and alternatives must be evaluated separately.
- **AWS S3 and HYCU:** Successful backup execution alone does not establish disaster recovery readiness; isolated restoration, integrity checks, and observed recovery time are required.
- High-risk activities, including production firewall changes, firmware upgrades, hyperconverged cluster maintenance, and privileged account operations, require authorization, rollback planning, and appropriate supervision.
